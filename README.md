# react-native-safe-area-context evidence

Before/after device captures for my react-native-safe-area-context pull requests. Every pair comes from one device in one run: `before` is the stock release its PR comment names, `after` is the same scene with the PR applied, and nothing else differs. Each capture is cropped to the probe.

Android captures come from a stock emulator at 1140x2400, density 480.
